# Programação em Python

Repositório para estudo e prática de conceitos básicos de programação em Python.

## Objetivo

Este projeto reúne materiais didáticos, exemplos e exercícios para apoiar o aprendizado de lógica de programação e estruturas fundamentais da linguagem.

## Conteúdo

O repositório pode incluir:

- notebooks com exemplos práticos;
- exercícios de fixação;
- explicações de estruturas de controle;
- materiais para estudo inicial em Python.

## Requisitos

- Python 3.9+
- Jupyter Notebook ou JupyterLab

## Como configurar o ambiente

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

## Como abrir os notebooks

```bash
jupyter notebook
```

Ou:

```bash
jupyter lab
```
